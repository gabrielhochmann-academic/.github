# Gabriel Hochmann Academic Projects

[Português](README.md) | [English](README.en.md)

This organization hosts coursework, technical studies, and collaborative projects developed during the Computer Science undergraduate program at the State University of Western Paraná (Unioeste).

## Principles

- **Clear authorship:** each repository should identify participants and relevant contributions.
- **Responsible privacy:** the visibility of each project is defined according to its academic context and the agreement of its participants.
- **Objective documentation:** projects should include execution instructions, references, and evidence when needed.
- **Conscious collaboration:** write permissions are granted only when maintenance or review is necessary.

## Repository organization

Each course or project may have its own repository, documentation, and version history. Build artifacts, credentials, personal data, internal documents, and unauthorized materials must not be published.

## Collaboration

Participants may be recognized in project documentation and invited to collaborate when future work is expected. Commit history should reflect actual contributions.
