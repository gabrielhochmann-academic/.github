# Projetos Acadêmicos de Gabriel Hochmann

[Português](README.md) | [English](README.en.md)

Organização destinada a trabalhos de disciplinas, estudos técnicos e projetos colaborativos desenvolvidos durante a graduação em Ciência da Computação na Universidade Estadual do Oeste do Paraná (Unioeste).

## Princípios

- **Autoria clara:** cada repositório deve identificar os integrantes e as contribuições relevantes.
- **Privacidade responsável:** a visibilidade de cada projeto é definida conforme o contexto acadêmico e a concordância dos participantes.
- **Documentação objetiva:** trabalhos devem conter instruções de execução, referências e evidências quando necessárias.
- **Colaboração consciente:** permissões de escrita são concedidas somente quando houver necessidade de manutenção ou revisão.

## Organização dos repositórios

Cada disciplina ou projeto pode ter seu próprio repositório, documentação e histórico de versões. Arquivos de compilação, credenciais, dados pessoais, documentos internos e materiais não autorizados não devem ser publicados.

## Colaboração

Participantes podem ser reconhecidos na documentação do projeto e convidados para colaborar quando houver atividade futura. O histórico de commits deve representar contribuições reais.
