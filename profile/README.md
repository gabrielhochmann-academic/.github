# Gabriel Hochmann Academic Projects



A private-by-default workspace for academic coursework, collaborative projects, and traceable technical learning.



## Working principles



This organization is designed to preserve a clear record of how projects evolve while respecting privacy, authorship, and academic integrity.



**Privacy by default.** Repositories remain private unless their visibility is explicitly reviewed and approved.



**Traceable work.** Commits, pull requests, and project boards record the actual state of work.



**Transparent authorship.** Contributions are attributed through repository history and reviewed project records.



**Controlled collaboration.** Access is granted through subject-specific teams and the minimum permissions needed.



**Sustainable learning.** Each discipline can use its own repository, team, documentation, and automation without exposing unrelated work.



## Collaboration standard



Academic collaborators are invited as regular organization members or outside collaborators when appropriate. Administrative access, repository visibility changes, integrations, and transfers remain under explicit owner control.



## Repository standards



Repositories should include concise documentation, an appropriate `.gitignore`, and workflows only when they match the project’s actual language, build process, and delivery requirements. Credentials, environment files, institutional data, and unreviewed generated material must not be committed.
